# new-feature-slice (skill)

Plugin: `dotnet-angular`

## What it does

Scaffolds a feature in the API and the Angular app by copying the shape of an existing slice, including README and tests.

## Why

Consistent slices are easy to review and find. Copying a real slice beats inventing a layout.

## How to adapt

Name a model slice and your folder and naming rules in `CLAUDE.md`. If your repo is not organized by feature, skip this skill.
